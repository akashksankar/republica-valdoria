## 🌟 Executive Summary

**REPUBLICA** puts you in the shoes of an ambitious sovereign oligarch in the fictitious island superpower of the **Republic of Valdoria**. 

Starting with modest liquid capital in Valdor Crowns (**VLC**), navigate a living macro-economy, build corporate conglomerates across 8 industrial districts, manipulate the Valdoria Stock Exchange (**VSE**), acquire luxury real estate, lobby parliamentary coalitions, and rise from private industrialist to Minister or Head of State.

## ⚡ Core Feature Showcase

### 🗺️ 1. Elevated Strategic God-View Map
- **Interactive Canvas Engine**: Smooth 60fps pan, pinch-zoom, and responsive multi-touch navigation.
- **8 Distinct Sovereign Districts**:
  - 🏛️ **Aurelia Capital District**: Government citadel, central banking reserve, high finance.
  - ⚓ **Port Azure Harbor**: Deep-sea maritime container shipping and naval trade.
  - 🔬 **Novara Silicon Corridor**: Semiconductor fabricators, venture capital, cybernetic institutes.
  - 🌋 **Ironvale Foundry Belt**: Heavy metallurgy, steel mills, rail transit networks.
  - 🌾 **Greenridge Heartland**: Agro-industrial breadbasket and agrarian cooperatives.
  - 🏖️ **Solmere Riviera**: Luxury hospitality, diplomatic villas, casino resorts.
  - ⚡ **Northmark Geothermal Reach**: Clean energy plants and mineral mining.
  - 🚂 **Eastford Transit Crossroads**: Freight hubs, wholesale logistics, domestic freight rail.
- **Data-Driven Heatmaps**: Instant diagnostic overlays for GDP Output, Density, Territorial Wealth, Unemployment, and Infrastructure health.
- **Living World Animations**: Dynamic coastal cargo ships and animated trans-territory freight trains.

---

### 📈 2. Deterministic Macroeconomic Engine
- Real-time calendar time engine with pause, **1x**, **2x**, **5x**, and **10x** simulation speeds.
- Interconnected macroeconomic indicators:
  - 💰 **Gross Domestic Product (GDP)** & growth rates.
  - 🏷️ **Consumer Price Inflation** & Central Bank interest benchmarks.
  - 👷 **National Labor & Unemployment rates**.
  - 🪙 **Currency Strength**: The Valdor Crown (**VLC**) backed by sovereign gold & credit reserves.
  - ⚖️ **Fiscal Deficits & National Debt clocks**.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ or 20+ recommended)
- `npm` or `pnpm` or `bun`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/republica-valdoria.git

# 2. Enter project directory
cd republica-valdoria

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open your browser at `http://localhost:3000` to begin your reign.

### Production Build

```bash
npm run build
npm run preview
```

## 🎮 Controls & Hotkeys

- **Drag / Swipe**: Pan the isometric map across districts.
- **Mouse Wheel / Pinch**: Zoom in/out of specific territorial sectors.
- **Speed Toggles**: `0x` (Pause), `1x` (Standard), `2x` (Accelerated), `5x` (Rapid), `10x` (Sprint).
- **HUD Net Worth Badge**: Inspect personal audited balance sheet, bank facilities, and credit lines.
